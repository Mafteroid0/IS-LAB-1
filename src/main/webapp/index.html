Координаты

Общие координаты могут использоваться несколькими маршрутами. При удалении используемой точки выберите замену.

СВЯЗАННЫЕ ОБЪЕКТЫ

Локации

Локация может быть отправлением и назначением разных маршрутов. Изменение локации отразится во всех связанных маршрутах.
