# Нагрузочный сценарий JMeter

Файл: `routes-concurrency.jmx` (Apache JMeter 5.6+, Groovy входит в дистрибутив).

Что проверяет — см. раздел 6 отчёта [`docs/REPORT.md`](../docs/REPORT.md): CRUD и импорт при параллельной работе
пользователей, гонки за уникальные значения (маршрут, локация, координаты, импорт одного файла) и гонки
изменения и удаления одного объекта несколькими пользователями.

## Подготовка

1. Запустите приложение и БД (см. [README](../README.md)).
2. Группы потоков выполняются **последовательно** (`serialize_threadgroups`), порядок важен.

## Запуск без GUI

```bash
jmeter -n -t jmeter/routes-concurrency.jmx -l target/jmeter.jtl -Jhost=localhost -Jport=8080 -Jusers=10 -e -o target/jmeter-report
```

Параметры:

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `-Jhost`, `-Jport` | `localhost`, `8080` | адрес приложения (контекст `/routes` уже в путях запросов) |
| `-Jusers` | `10` | число параллельных пользователей в группе CRUD |
| `-Jrun` | `MMddHHmm` текущего времени | суффикс уникальных значений; при повторном запуске в ту же БД в течение той же минуты задайте новый, например `-Jrun=1234` |

Группы гонок рассчитаны на 8 потоков (значение `groupSize` у Synchronizing Timer должно совпадать с числом потоков).
Значение `run` должно быть числом не больше 8 цифр: оно используется и в координатах.

## Как читать результат

- Ожидаемые отказы (`409`, `404`) в гонках не считаются ошибками: утверждения о коде ответа работают в режиме «игнорировать статус».
- Любой неожиданный код (в том числе `500`) или нарушение счётчиков в последней группе («ровно один победитель») отображается как ошибка сэмплера.
- Счётчики побед хранятся в свойствах JMeter (`ok.*`) и живут в пределах одного запуска JVM, поэтому каждый запуск делайте новой командой `jmeter -n`.

## Скрипт без JMeter

`concurrency_check.py` выполняет тот же сценарий на стандартной библиотеке Python (JMeter не нужен); приложение
нужно запустить с `APP_ADMINS=boss`, адрес задаётся `BASE_URL`:

```bash
BASE_URL=http://localhost:8080/routes/api python jmeter/concurrency_check.py
```

## Примечание

Файл создан генератором и проверен на корректность XML, но на машине разработки JMeter не устанавливался, поэтому
сам запуск плана в JMeter не выполнялся; тот же сценарий проверен отдельным скриптом (см. отчёт, раздел 6).
